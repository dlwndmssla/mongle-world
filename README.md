# 몽글월드

따뜻한 아이보리 배경 위에서 파스텔 클레이 지구본을 돌리며 나라를 탐험하는 React + Three.js 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

표시된 로컬 주소를 브라우저에서 열면 됩니다.

## 포함 기능

- 자동 회전, 드래그, 휠/핀치 확대·축소
- 실제 World Atlas 기반 국가 경계와 섬
- 대한민국·일본·프랑스 선택 버튼 및 지구 위 클릭 포인트
- 선택 국가로 부드럽게 회전/확대
- 랜드마크·국화·상징 동물 미니어처가 표면 법선 방향으로 솟아나는 연출
- 반응형 모바일 레이아웃
