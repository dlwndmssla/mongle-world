# 몽글월드

낯선 행성에서 자원을 확보하고 지식을 복원해 집으로 돌아갈 준비를 하는 생존·연구 게임입니다. React + Three.js와 Canvas 기반 탐험 지도를 사용합니다.

## 실행

```bash
npm install
npm run dev
```

표시된 로컬 주소를 브라우저에서 열면 됩니다.

## 포함 기능

- 수학 38개·과학 35개·물리 37개 주요 개념과 로켓·로봇·재배·기억 연구 32개. 특정 국가 교육과정의 완전한 수록을 뜻하지 않습니다.
- 풀이 문제 없이 연구 선행 조건과 제작 해금을 연결하고, 복원 시 짧은 공식 알림을 표시합니다.
- 특정 원소가 모인 광맥에 전용 광산을 건설합니다. 확인·추정 원소의 생성과 채굴 확률은 게임 밸런스 값입니다.
- 전력 소모와 저장 용량이 있는 자동채굴, 물·양분·종자·전력을 소비하는 온실 생산.
- 단일단 이상 로켓 방정식·추력중량비에 기반한 예비설계 계산, 별도 정적 시험과 365일 생존 발사 조건.
- 위치 핀 이동, 가장자리 카메라 추적, 해안에서 승하선하고 자리에 남는 배, 1×/10×/60× 시간 배속.
- 행성별 브라우저 자동저장. 새로고침과 궤도 복귀 후 같은 행성에서 이어갈 수 있습니다. 브라우저를 닫은 동안은 시뮬레이션이 진행되지 않습니다.

## 검증

```bash
node --test tests/simulation.test.mjs
npm run build
```

로켓 계산은 일정 비추력·단일단·구형 천체의 표면 근사이며, 회전과 실제 궤적 적분을 생략합니다. 항력·중력 손실은 사용자가 입력하는 예산으로 처리합니다. 질량 슬라이더는 게임 내 제작 원료의 실제 질량 환산을 뜻하지 않습니다. 저궤도 예비 성능 판정은 실제 비행의 충분조건이 아닙니다. 365일 제한, 작물 성장 시간, 설비 전력과 수율은 게임 규칙입니다.
